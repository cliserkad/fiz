# Project Goals

## Language

- Intuitive syntax
- Efficient Error Handling
- Automatic casting
- Operator overloading
- Nullable / result types

## Build System

- Host packages at pkg.fiz.dev
- Compatible with maven dependencies
- Format, compile, test and publish packages
- Git based versioning

## Formatter

## Testing Platform

- 'assert' based testing
- unit tests
- mocks
- method stubs

## Logging Framework

- disable log statements at compile time
- set log level at runtime
- consolidate / coalesce log events
- filter on log level
- filter on source code location
- filter on message content
- filter on thread
- filter on exception type
